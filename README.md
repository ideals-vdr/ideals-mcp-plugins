# Ideals MCP plugins

Marketplace plugins that connect AI agent platforms to the [Ideals Virtual Data Room](https://www.idealsvdr.com) MCP server.

| Platform | Plugin |
|---|---|
| Google Antigravity | [`plugins/ideals`](plugins/ideals) |

All plugins point to the same remote MCP server, `https://gateway.idealsvdr.com/mcp`, which uses OAuth 2.0 sign-in with an Ideals account.
