# Ideals MCP plugins

Plugins and connector packages that connect AI tools to [Ideals Virtual Data Room](https://www.idealsvdr.com) through the Ideals MCP server (`https://gateway.idealsvdr.com/mcp`, OAuth 2.0 with PKCE).

| Folder | Tool |
|---|---|
| [`antigravity/`](antigravity/) | Google Antigravity plugin |

Each folder is self-contained and has its own README with setup steps.

- Help center: https://helpcenter.idealsvdr.com
- Privacy policy: https://www.idealsvdr.com/privacy/
